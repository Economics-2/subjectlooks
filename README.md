# সাবজেক্ট লক ভিডিও মেকার (MH Academy)
## ১) PWA (GitHub Pages)
1. GitHub-এ নতুন repo বানান, এই ফোল্ডারের সব ফাইল (`.github` সহ) আপলোড করুন (branch: main)
2. Settings → Pages → Source: **GitHub Actions**
3. Actions ট্যাবে "Deploy PWA" শেষ হলে লিংক পাবেন → ফোনের Chrome-এ খুলে "Install app / Add to Home screen"
## ২) APK
PWA লাইভ হলে https://www.pwabuilder.com এ লিংক দিন → Android → Download (APK/AAB)
## ৩) Windows EXE
repo-র Actions → "Build Windows EXE" → Run workflow → শেষে Artifacts থেকে `.exe` নামান
